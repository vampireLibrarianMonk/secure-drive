# Independent Recovery (spec §6)

**Mandatory requirement.** The encrypted documents must never become
permanently dependent on the Emergency Archive application. If this project
disappears 15 years from now, a technically competent person with:

- the USB drive,
- the password,
- maintained open-source recovery software,
- and `RECOVERY-INSTRUCTIONS.txt` (in the drive's `public/` folder),

must be able to recover the documents.

## Chosen format → recovery path

The vault is a **Cryptomator vault format 8** archive (see
[CRYPTOGRAPHY.md](CRYPTOGRAPHY.md)). Recovery paths, strongest first:

1. **The Cryptomator application** — free, open source (GPLv3), actively
   maintained for Windows/macOS/Linux/Android/iOS. Install it, add the
   drive's `vault\` folder as an existing vault, unlock with the archive
   password, copy the documents out. No technical skill required beyond
   following the on-drive instructions.
2. **Any other Cryptomator-format-compatible tool** — the format is public
   and documented by Cryptomator (docs.cryptomator.org → Security).
3. **Manual decryption** — the format summary in CRYPTOGRAPHY.md plus the
   on-drive instructions are sufficient for a competent person to implement
   the decryption with any standard crypto library.

## Where recovery instructions live

1. `public/RECOVERY-INSTRUCTIONS.txt` on every USB drive — human-readable,
   no secrets, regenerated by the build (`scripts/new-usb.ps1`) and
   exportable from Setup Mode.
2. This document — the engineering source of truth and checklist.

## Required contents of the on-drive instructions

- Identification of the format: Cryptomator vault format 8 (SIV_GCM),
  masterkey file version 999, scrypt KDF parameters as stored in
  `vault\masterkey.cryptomator`.
- Which files hold encrypted data: everything under `vault\` (`d\` tree,
  `masterkey.cryptomator`, `vault.cryptomator`).
- Recovery software: the Cryptomator application (download address included
  on the drive), plus the fallback manual procedure.
- Step-by-step unlock/copy-out procedure.
- Never: the password, key material, or anything else secret.

## Author checklist (per release)

- [ ] Recovery exercise: create a vault with Emergency Archive, recover it
      using ONLY the Cryptomator application and the instructions file.
- [ ] Verify the instructions work on a clean Windows VM without Internet.
- [ ] Verify version numbers referenced in the file match the vault.
- [ ] Repeat for every major release (and after any crypto change).
