# SBOM

Generated CycloneDX Software Bill of Materials for the Emergency Archive.

Regenerate with:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\generate-sbom.ps1
```

Output: `sbom/bom.json` (CycloneDX JSON, generated by the tool version pinned
in `dotnet-tools.json` at the repository root, against the package versions
pinned in `Directory.Packages.props`).

Generated SBOM files are not committed — regenerate per release and archive
them with the release artifacts (specification §28, Phase 7 hardening).
